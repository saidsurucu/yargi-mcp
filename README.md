# Yargı MCP → Yargı PRO

Bu proje Yargı PRO'ya taşındı.

Yargı MCP, Türk mahkeme kararlarını yapay zekâ asistanlarına MCP üzerinden bağlayan açık kaynak bir
projeydi. Ücretsiz barındırılan sürümü (`yargimcp.surucu.dev`) kapatıldı; bu adres artık hizmet vermiyor.

Aynı bağlantı, bakımı yapılan bir hizmet olarak Yargı PRO'da sürüyor:

- **MCP adresi:** `https://app.yargipro.com/mcp`
- **Kurulum:** https://www.yargipro.com/kilavuz/mcp-kurulumu (Claude, ChatGPT/Codex, Gemini/Antigravity,
  Cursor, VS Code, Claude Code ve diğer MCP istemcileri)
- **Kapsam:** Yargıtay, Danıştay, istinaf ve yerel mahkeme kararları (~11 milyon), Anayasa Mahkemesi,
  mevzuat (12 tür), Resmî Gazete ve 18 kurumun kararları (Rekabet Kurulu, KVKK, BDDK, SPK, Sayıştay, KİK,
  GİB özelgeleri…)
- **Deneme:** 14 gün, ödeme bilgisi istenmez → https://www.yargipro.com
